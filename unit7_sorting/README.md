## Reflection
While completing this assignment, I learned how Bubble Sort and Merge Sort organize data and how their performance changes as the size of the dataset increases. I practiced using nested loops, recursion, dividing a list into smaller parts, and merging sorted lists. I also learned that an algorithm that works well for a small dataset may not be efficient for a large dataset.

One challenge I encountered was understanding the recursive process in Merge Sort. I overcame this by breaking the algorithm into smaller steps: divide the list, recursively sort each half, and then merge the two sorted halves. Testing the algorithms with different datasets and edge cases also helped me understand their behavior.

Bubble Sort has a time complexity of O(n²) in its average and worst cases, so it can become slow as the dataset grows. Merge Sort has a time complexity of O(n log n), which makes it more suitable for large datasets. Bubble Sort can still be useful for small or nearly sorted lists, while Merge Sort is a better choice when processing large amounts of data. A real-world example would be using Merge Sort to organize large content or recommendation lists on a streaming platform.
